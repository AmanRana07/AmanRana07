## ◈ FEATURED MISSION // 001 ◈

### 🚄 RAILWAY AI — PANTOGRAPH INTELLIGENCE

<img width="90%" src="https://capsule-render.vercel.app/api?type=rect&height=100&text=VISION%20%7C%20MEASUREMENT%20%7C%20ANALYTICS&fontSize=20&fontColor=00F7FF&color=0:080B18,50:191044,100:003B57&animation=fadeIn" />

</div>

An industrial computer vision system focused on real-time railway pantograph and overhead equipment monitoring.

| Module | Capability |
|---|---|
| Vision Engine | Detect pantographs, contact wires, and railway components |
| Spark Analytics | Analyze electrical sparks and visual anomalies |
| Measurement Engine | Estimate height, stagger, and related geometry |
| Depth Integration | Work with Intel RealSense depth-camera data |
| Inference Pipeline | Run multiple AI models in a real-time processing workflow |
| Monitoring Dashboard | Display detections, measurements, and session information |

<details>
<summary><b>⚙️ Explore the technical architecture</b></summary>

- Python and PyTorch-based computer vision.
- YOLO-based detection and segmentation pipelines.
- OpenCV video processing.
- GPU-accelerated model inference.
- FastAPI backend integration.
- Calibration, measurement smoothing, and data logging.

</details>
